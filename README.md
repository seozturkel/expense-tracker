# 💰 Kişisel Bütçe ve Harcama Analiz Sistemi (Expense Tracker SQL)

Bu depo, SQL öğrenme sürecimde veritabanı tasarımı, DDL/DML komutları ve analitik sorgulama becerilerimi geliştirmek amacıyla oluşturduğum kişisel bir projedir.

## 🚀 Proje Hakkında
Proje, günlük harcamaların kategorize edilerek takip edilmesini ve bu veriler üzerinden anlamlı finansal raporlar çıkarılmasını sağlayan ilişkisel bir veritabanı yapısı sunar.

## 🗄️ Veritabanı Şeması
Projede iki temel tablo bulunmaktadır:
1. **Kategoriler:** Harcamaların türlerini tutar (Market, Fatura, Ulaşım vb.).
2. **Harcamalar:** Gerçekleşen harcama miktarını, tarihini ve ilgili kategoriyi barındırır.

## 📊 Örnek Analitik Sorgular
Depo içindeki SQL dosyalarında şu tarz gelişmiş sorgular yer almaktadır:
- Kategorilere göre toplam harcama analizi (`GROUP BY` ve `JOIN`)
- Genel ortalamanın üzerindeki harcamaların tespiti (`Subquery`)
